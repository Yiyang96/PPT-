
## 1. 产品概述
公众号数据分析工具是一个帮助内容创作者分析公众号运营数据、发现创作规律、提供内容建议的单页应用。通过数据可视化和智能分析，帮助创作者优化内容策略，提升账号影响力。

## 2. 核心功能

### 2.1 功能模块
1. **仪表板**：数据概览、关键指标卡片、趋势图表
2. **文章分析**：文章数据列表、阅读量/互动量分析
3. **内容建议**：基于数据的创作方向推荐

### 2.2 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 仪表板 | 关键指标卡片 | 展示总阅读量、总互动量、文章总数、平均阅读量 |
| 仪表板 | 趋势图表 | 阅读量和互动量的时间趋势折线图 |
| 仪表板 | 热门文章TOP5 | 阅读量最高的前5篇文章 |
| 文章分析 | 文章列表 | 所有文章的数据列表，支持搜索和排序 |
| 文章分析 | 文章详情卡片 | 单篇文章的详细数据和指标 |
| 内容建议 | 热门话题 | 基于数据分析的热门话题推荐 |
| 内容建议 | 最佳发布时间 | 分析最佳发布时段 |
| 内容建议 | 内容类型建议 | 推荐表现好的内容类型 |

## 3. 核心流程
用户进入应用后，首先看到仪表板，了解整体数据概况；然后可以查看文章分析，深入了解每篇文章的表现；最后通过内容建议获取创作方向。

```mermaid
flowchart TD
  A[仪表板] --&gt; B[文章分析]
  A --&gt; C[内容建议]
  B --&gt; A
  C --&gt; A
```

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深蓝色 (#1e40af) 配合青色 (#06b6d4) 作为辅助色
- 按钮风格：圆角矩形，轻微阴影，hover时有上浮动画
- 字体：使用无衬线现代字体，标题采用有设计感的展示字体
- 布局风格：卡片式布局，网格系统
- 图标风格：使用Lucide图标库，线条简洁

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 仪表板 | 关键指标卡片 | 渐变背景，数值放大显示，图标点缀 |
| 仪表板 | 趋势图表 | 响应式图表，渐变线条，动画效果 |
| 文章分析 | 文章列表 | 卡片式展示，hover效果，数据标签 |
| 内容建议 | 建议卡片 | 暖色调，图标引导，清晰建议文本 |

### 4.3 响应性
桌面优先设计，同时完美适配平板和移动设备，触控优化。
